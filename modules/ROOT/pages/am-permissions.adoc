Anypoint Monitoring has product-specific permissions that control access to its assets:

//all monitoring permissions
include::access-management::partial$include-permissions-monitoring.adoc[tag=permsMonitoringAll]

Access to data for users to with Anypoint Monitoring Administrator and Anypoint Monitoring Viewer permissions depends on other asset-specific permissions. To view or modify data related to specific apps and APIs, you also need the appropriate access permissions for those assets. For example, a user who has the Anypoint Monitoring Viewer permission and wants to view Anypoint Monitoring data for an on-premises app also needs the Read Applications permission (from Runtime Manager) in the same environment that the app is deployed to.
