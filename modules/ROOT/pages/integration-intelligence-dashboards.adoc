[[more-actions]]
== Copy, Download, or Explore Metrics

Copy or download an image of any chart or table in a dashboard, or open a page dedicated to specific metrics. 

. In a chart or table in a dashboard, click an empty area, and then hover to display a image:ii-menu-arrow-icon.png["",15,15] (menu arrow).
. Click image:ii-menu-arrow-icon.png["",15,15] (menu arrow). 
. Select an option:

* *Copy Image*: Copies a screenshot of the chart or table to your clipboard.
* *Download Image*: Downloads a screenshot of the chart or table to your local drive.
* *Explore*: Opens a new tab that contains the selected chart or table on a full page. You can also add the chart to an existing dashboard or create a dashboard for the chart from this page.  
+
In the Beta, any new dashboards that you create won't reside in Integration Intelligence. Instead, they'll be accessible from a Tableau Next workspace that you create.

To create a dashboard in Tableau Next, you first connect data in Data Cloud, build a reusable Semantic Model defining metrics and relationships, then create individual Visualizations from that model (e,g., bar, line charts), and finally drag those saved visualizations onto a new Dashboard canvas, adding context and interactivity before sharing. It's a structured, governed approach where the semantic model acts as the single source of truth. 


Step 1: Set Up & Connect Data (Data Cloud)
Get Data: In Data Cloud, bring in your data (e.g., sales data) as a governed dataset.
Add to Workspace: In Tableau Next, add this dataset to your workspace. 
This video shows how to add data and create a semantic model in Tableau Next:
https://encrypted-vtbn2.gstatic.com/video?q=tbn:ANd9GcS75P9Lab_63joC-7uZ9NWH0YcyNvvCT3LBxgfmG3zo0LNlNIkz


Step 2: Create the Semantic Model (Governed Logic)
Start New Model: In your workspace, choose to create a new Semantic Model.
Add Data Objects: Bring in related data objects (like Accounts, Users, Orders).
Define Relationships: Drag fields to link objects (e.g., Account ID to User ID).
Create Metrics: Define business logic like Profit Ratio = Profit / Sales.
Save: Save the model; it's now reusable for everyone. 
Watch this demo to see how to build a semantic model with relationships:

Step 3: Build Visualizations (The Charts)
New Visualization: In your workspace, create a new Visualization using your Semantic Model.
Drag & Drop: Drag fields (e.g., Sales, Category) to Rows/Columns/Color/Labels.
Choose Chart Type: Select Bar, Line, Donut, etc., from the Marks card.
Add Calculations: Use Quick Table Calculations (like Percent Difference) for deeper insights.
Save: Save each visualization (e.g., "Sales by Segment Donut", "Sales Over Time").

Step 4: Assemble the Dashboard (The Story)
New Dashboard: Create a new Dashboard in your workspace.
Add Visualizations: Drag your saved visualizations onto the canvas.
Arrange & Resize: Position and size elements as needed.
Add Interactivity: Make charts act as filters by clicking on them.
Context: Add titles and text boxes for clarity.
Share: Save and share your dashboard, ensuring governed data access.
