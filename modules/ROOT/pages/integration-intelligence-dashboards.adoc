== Supported Deployment Types

Integration Intelligence supports Mule apps and Mule APIs deployed to these hosts:

//* CloudHub
* CloudHub 2.0 
* Runtime Fabric
//* Hybrid

Unsupported at this time:

* Flex Gateway APIs
* Agentic assets (brokers, agents, and MCP servers)

For information about hosts, see xref:hosting-home::index.adoc#runtime-plane-hosting-options[Runtime Plane Hosting Options].
