= Configuring Text Panels in a Custom Dashboard
:page-info-pills: anypoint-pricing-titanium

Configure HTML and Markdown text panels in Anypoint Monitoring custom dashboards.

[[prereqs]]
== Before You Begin

Create or navigate to the text panel you plan to configure:

* If your text panel exists, open its configuration view:

. From *Custom Dashboards*, open the custom dashboard that contains your text panel.
+
For guidance, see xref:dashboard-custom-config.adoc#view[View a Custom Dashboard].
. Click the text panel's image:more-menu-vert-ellipsis.png["",15,15] (*More menu*), and select *Configure*.

* If the text panel doesn't exist:

. Create the text panel.
+
For guidance, see xref:dashboard-custom-config.adoc#charts_adding[Add Charts to a Custom Dashboard].
. Navigate to its configuration view.

[[create]]
== Create a Text Panel

Create a text panel in a custom dashboard by following the guidance in xref:dashboard-custom-config.adoc#charts_adding[Add Charts to a Custom Dashboard].

[[configure]]
== Configure a Text Panel

Configure a panel with HTML or Markdown text in a custom dashboard.

. From *Custom Dashboards*, open the custom dashboard that contains your text panel.
+
For guidance, see xref:dashboard-custom-config.adoc#view[View a Custom Dashboard]. 
. Click the panel's image:more-menu-vert-ellipsis.png["",15,15] (*More menu*), and select *Configure* to open the panel's *General* configuration tab:

.. Provide a title and description.
.. Select the *markdown* or *html* mode.
.. Provide content in the selected mode.
+
For examples and more detailed steps, see:

* <<markdown>>
* <<html>>
. Click *Apply Changes*. 
. Exit the configuration view by clicking the *X* next to the configuration tabs.
