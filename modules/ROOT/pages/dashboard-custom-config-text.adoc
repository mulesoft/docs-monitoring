= Configuring Text Panels in a Custom Dashboard
:page-info-pills: anypoint-pricing-titanium

Configure text panels in Anypoint Monitoring custom dashboards.

Supported formats:

* HTML: See xref:dashboard-config-ref.adoc#samples_html[HTML Support] for HTML examples.

* Markdown: See xref:dashboard-config-ref.adoc#samples_markdown[Markdown Syntax Support] for Markdown examples. 

[[prereqs]]
== Before You Begin

Open the text panel's configuration view.

* To open the text panel's configuration view, click its image:more-menu-vert-ellipsis.png["",15,15] (*More menu*), and select *Configure*.
* To create a text panel in a custom dashboard, see xref:dashboard-custom-config.adoc#charts_adding[Add Charts to a Custom Dashboard].

After you complete your configuration, you can click Save Changes. To exit the configuration and return to the dashboard, simply click the `X`.
