= Setting Up Advanced Alerts in Anypoint Monitoring

include::reuse::partial$billing/pricing.adoc[tag=featureAdvReq]

Set up advanced alerts for charts in xref:create-custom-dashboard.adoc[custom dashboards], from the chart's *Alert* tab. Alerts trigger email notifications if a data point you're measuring passed a specified threshold in the past 5 minutes. This 5 minute period is fixed and not configurable. 

For apps that run on more than one worker, charts that display worker-related metrics in Anypoint Monitoring dashboards break down the metrics by worker. 

When you configure an advanced alert for a graph, an alert state icon appears in the chart.

image::alert-in-graph.png["Line chart showing CPU usage over time with an alert state of OK"]

Hover over the bell icon to trigger a description popup. In this case, the description indicates `Status OK`.
