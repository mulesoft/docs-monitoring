You can set up advanced alerts for graphs in custom dashboards. Alerts trigger email notifications when a data point you are measuring passes a specified threshold. Advanced alerts are listed in the *Alerts* page in Anypoint Monitoring.

When you configure an advanced alert for a graph, an alert state icon appears at the top of the graph.

image::alert-in-graph.png["Line chart showing CPU usage over time with an alert state of OK"]

Hover over the bell icon to trigger a description popup. In this case, the description indicates `Status OK`.
