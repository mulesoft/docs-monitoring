== Search for Logs

. Select a date-time range (defaults to the last 15 minutes).
+
Built-in and custom selections are available for up to the last 30 days of logs for selected time ranges. 
. Select an environment.
. To narrow the search results, provide a <<ref-query, log query>>.
. Review the search results.
+
You can expand a log entry to get additional details.
+
If no logs return, try a different date-time range, query, or environment. Also review the <<search-query-rules, search query behavior>>.

[[refresh]]
== View the Latest Logs

After a search query executes and produces log data (or no results), no new log data appears until you perform a new query, refresh, or reload the page. 

To retrieve the latest log data, click *Refresh*. 

[[environments]]
== Environments

When displaying logs, select the environment containing the logs you intend to review.

Built-in xref:access-management::environments#types-of-environments.adoc[environments] are:

* *Environment: Design*
* *Environment: Production*
* *Environment: Sandbox*

Any other environments that your organization xref:access-management::environments.adoc#to-create-a-new-environment[creates] are also available.

[[ref-query]]
== Log Query Reference

Use filters to narrow the results of your search for logs. The filters match values of fields in the logs:

* `application` accepts an *=* operator followed by an application name. 
* `log_level` accepts an *=* operator followed by a value of *DEBUG*, *INFO*, *WARN*, *ERROR*, or *FATAL*. 
* `message` accepts a *LIKE* operator for partial or exact matches in log `message` fields. 

[[search-query-rules]]
Search query behavior:

* You can use any or all of the available filters in your query.
+
Multiple filters in a query are processed as logical ANDs (and not as ORs), meaning that searches return data matching all the filter criteria, not just some of it. 
* Multiple filters of the same type, such as two `application` filters, aren't allowed. 
* Each filter allows a single value. 
* For single-word search string values, you do not need to add quotation marks around search the string. For multi-word strings, manually surround the string in quotes. 
* Some message searches must provide an exact match. For example, a match to `package` in a package name like `com.some.package.name` isn't supported.
